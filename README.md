# Portfolio · Mario Ramos Tuñón

Web estática (HTML + CSS), sin dependencias ni build.

- `index.html` — portfolio
- `cv.html` — CV (se abre en `/cv`, con botón para guardarlo en PDF)
- `vercel.json` — URLs limpias (`/cv` en vez de `/cv.html`)

## Publicar en Vercel
Import del repo en vercel.com → Framework preset: **Other** → Deploy.
Cada push a `main` vuelve a publicar la web.
